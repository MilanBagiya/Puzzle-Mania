## Accessibility (WCAG 2.2 AA)
- Boards use `role="grid"` with no rows/cells or arrow keys (all boards, `shared.ts:73`).
- Search box has no `role="combobox"` / `aria-expanded`; Options choices are 15 separate tab stops with invalid `aria-selected` on radios; menu button `aria-expanded` wrong on desktop.
- Screen readers can't play: Feather Pairs (cards say only "Card showing"), Egg Match (guesses hidden), Otter Slide (pipe directions), Burrow Escape and Moose (no positions); Track Word delete key unlabeled; Who Ate / Snow Picture use `aria-selected` on buttons.
- Visual-only info: Mushroom Rings "ghost ring", Stepping Stones hint labels, Frog Pond patches by colour alone (some colours very close).
- Remaining colour/background hovers outside the hover media query: `styles.css:48, 529, 534, 735`.

## Tests that don't test enough
- Pack tests t1–t3 use only `'d'+n` seeds (real seeds are dates); Leaf Pile test compares the solver to itself; Pairs test only counts 16 cards.
